# Personal GPU Deploy — Phase 1: Monorepo Restructure — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the single-package `ui-perception-engine` repo into a `pnpm` workspace with the existing engine extracted into `packages/core/` and a new `packages/contracts/` package proving the cross-package boundary works — all 498 existing tests staying green and `tsc` clean throughout.

**Architecture:** The engine uses relative imports with `.js` extensions and **no path aliases** (confirmed: `tsconfig.json` has no `paths`). Moving the entire `src/` and `tests/` trees wholesale into `packages/core/` therefore preserves every internal import unchanged — the only changes are workspace/tsconfig/vitest/script config and one new cross-package dependency. Rust (`crates/`, `Cargo.toml`), the Python `sidecar/`, and `landing/` stay at the repo root for this phase (the Python sidecar becomes `packages/vision-svc/` in Phase 2).

**Tech Stack:** pnpm workspaces, TypeScript NodeNext + project references, Vitest, the existing engine deps (Playwright, sharp, @modelcontextprotocol/sdk, zod, @anthropic-ai/sdk).

**Spec:** [`docs/superpowers/specs/2026-05-31-personal-gpu-deploy-design.md`](../specs/2026-05-31-personal-gpu-deploy-design.md) — Units 1–2.

**Execution note:** This restructure touches many files via `git mv`. Run it in an isolated worktree (superpowers:using-git-worktrees) so the move can be discarded cleanly if it goes sideways. Branch base: `feat/personal-gpu-deploy`.

- [ ] **Step 1: Write the failing cross-package test in core**

Create `packages/core/tests/unit/contracts-boundary.test.ts`:

```typescript
import { describe, it, expect } from 'vitest';
import { VISION_API_VERSION, type VisionAnalyzeRequest } from '@uipe/contracts';

describe('@uipe/contracts boundary', () => {
  it('core can import the versioned vision API contract', () => {
    expect(VISION_API_VERSION).toBe('v1');
  });

  it('VisionAnalyzeRequest shape is usable from core', () => {
    const req: VisionAnalyzeRequest = {
      apiVersion: 'v1',
      pngBase64: 'iVBORw0KGgo=',
      regions: [{ x: 0, y: 0, w: 10, h: 10 }],

    expect(req.apiVersion).toBe('v1');
    expect(req.regions).toHaveLength(1);
  });
});
```

export const VISION_API_VERSION = 'v1' as const;

export interface BBox {

  y: number;

  h: number;

  /** Regions of interest to classify; empty means whole-frame. */
  regions: BBox[];
}
